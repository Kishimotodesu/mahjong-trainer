# 麻雀トレーナー(V1.4)

麻雀初心者が、CPU3人と実際に対局しながら、

- 何を切ればいいのか(牌効率)
- なぜその牌なのか(理由の解説)
- どうすればアガれるのか(役・ドラ・符・点数)
- どう守ればいいのか(安全牌・押し引き)

を身につけられる、一人用のローカル学習Webアプリです。サーバー・ログイン・課金は一切ありません。

- **V1.1まで**: 牌効率(シャンテン数・有効牌・受け入れ枚数)の学習に特化
- **V1.2で追加**: 役・翻・符・点数の判定と、その「なぜ成立しているのか」の解説
- **V1.3で追加**: **CPU3人との実戦対局**(鳴き・リーチ・フリテン込み)、対局中コーチ、
  安全牌・押し引きの参考表示、牌譜保存・再生・復習、局面のJSON書き出し/読み込み、学習メニュー
- **V1.4で追加**: **何切る復習帳**。間違えた「何切る」が自動で問題帳に貯まり、
  同じ問題を繰り返し解いて「なぜこの牌なのか」を覚えられる。学習レベル別出題・苦手分析・習得判定つき

## 公開URL(スマホ対応)

**https://kishimotodesu.github.io/mahjong-trainer/**

iPhone / Android の Chrome・Safari からこのURLを開くだけで、インストール不要でそのまま遊べます。
成績・牌譜はブラウザのlocalStorageに保存されるため、同じ端末・同じブラウザなら次回も残ります
(端末をまたいだ同期はしません)。

## クイックスタート

1. 上記URLを開く。または `index.html` をブラウザ(Chrome / Edge 推奨)でダブルクリックして開く
2. 「対局」タブで「対局を開始する」を押す
3. わからない牌があれば「コーチ:フルコーチ」の表示を参考にしながら打牌する
4. 対局後は「牌譜・復習」タブで、自分の打牌を振り返る

ビルド・インストール・外部APIキーは一切不要です。`npx serve .` 等で静的配信しても構いませんが必須ではありません。

## 「対局」タブの使い方

1. 対局形式(東風戦/東南戦)、CPUの強さ(初心者/標準/強め)、コーチ(OFF/ヒント/フルコーチ)を選んで「対局を開始する」
2. 自分の手番になったら、手牌をクリックして選び「この牌を切る」。ツモ・リーチ・暗槓・加槓が可能な場合はボタンが表示される
3. 他家が捨てた牌に対してポン・チー・カン・ロンができる場合は選択肢が表示される(できなければ自動的にCPUの手番へ進む)
4. アガリ・流局になると結果が表示され、「次の局へ」で局を進められる。対局が終わると最終順位が表示される
5. いつでも「牌譜を保存する」でその時点までの記録を保存できる

### コーチ機能
- **OFF**: 何も表示しない(実戦さながら)
- **ヒント**: シャンテン数と、他家がリーチしている場合の比較的安全な牌のみ表示
- **フルコーチ**: 上位候補について「牌効率・打点・役・安全度」を◎○△×(該当なしは「ー」)で一覧表示し、
  押し引きの参考コメントと「なぜ?」ボタン(おすすめの理由の詳細)を表示

「牌効率上のおすすめ」と「役・打点・安全度」は必ず**別々に**表示し、総合コメントで初めて統合します
(牌効率だけを見て役や安全度を見落とさないようにするため)。

### 安全牌・危険度の考え方(根拠のある構造的判定のみ使用)
- **現物(絶対安全)**: 相手の捨て牌、またはリーチ後に他家が捨てて見逃された牌
- **場に4枚見え(絶対安全)**: その牌がもう場に残っていないため誰も待てない
- **スジ・ノーチャン(比較的安全)**: 両面待ち・嵌張待ちが構造的に成立しにくいことを示す参考情報であり、絶対ではありません
- **ワンチャン(やや安全)**: 嵌張に必要な牌が残り1枚
- 根拠のないランダムな数値による「危険率」は使用していません。

## 「復習帳」タブの使い方(V1.4)

**「問題を解いて終わり」ではなく、間違えた牌効率だけを繰り返し復習して覚えるための機能です。**

### 自動で貯まる
「何切る問題」で回答すると、次のいずれかに当てはまる場合は自動的に復習帳へ追加されます
(初心者が「何を保存すべきか」を判断しなくてよいようにするためです)。

- ×評価 / △評価だった
- 牌効率上の1位候補と違う牌を選んだ
- シャンテン数を戻してしまった
- 受け入れ枚数を大きく(4枚以上)減らした

自動保存されなかった問題も「復習に保存」ボタンで手動保存できます。
**同じ手牌は何度解いても1問としてまとめられ**、回答は履歴として追記されます(重複登録されません)。

### 今日の復習
「今日の復習を始める」で、5問(所要3〜5分)だけ出題します。出題順はルールベースで決まります。

1. まだ理解できていない問題(要復習)
2. 過去に×だった問題
3. 過去に△だった問題
4. 苦手タグと同じタイプの問題
5. 久しぶりに復習する問題

### もう一度解く → 前回との比較
保存した問題は答えを隠した状態で再出題されます。回答すると、前回・今回・おすすめを並べて表示し、
「改善しました!」のように変化が分かります。回答履歴(1回目: 5萬 △ → 2回目: 9索 ◎ …)も残ります。

### 習得判定

| 状態 | 条件 |
|---|---|
| 未復習 | まだ1回しか解いていない |
| 要復習 | 直近の回答が×または△ |
| 学習中 | 直近が○、または◎が1回だけ |
| 習得 | **直近2回連続で◎** |

習得した問題も削除されず、履歴として残ります。

### 学習タグと苦手分析
問題の特徴(孤立牌・両面・嵌張・辺張・対子・シャンテン戻し・受け入れ・複合形・字牌処理)を
既存の形判定ロジックから自動でタグ付けし、タグごとの正答率を集計して
「あなたが現在苦手なもの」を上位3つ表示します。初心者向けの説明つきです。

> 複合形: 3445萬のように、複数の使い道を持つ形を残す判断です。

### 解説の初心者化
復習の結果画面では、まず**「今回一番覚えてほしいこと」を1文だけ**表示します。
受け入れ枚数・シャンテン数などの詳細は「詳しく見る」を開いたときだけ表示されます。

### 成長表示
復習した問題数・習得・学習中・要復習・未復習の数と、今週の◎率を表示します。
ゲーム的な演出は入れず、「何が分かるようになったか」を中心にしています。

### 対局からの追加
CPU対局中の打牌のうち、**学習価値の高いものだけ**を自動で復習帳に追加します
(門前で14枚の場面に限り、シャンテンを戻した・受け入れを6枚以上減らした・
牌効率上の上位3候補から外れた、のいずれか)。大量に保存されないよう絞っています。

### データの移行(Export / Import)
スマホとPCのlocalStorageは共有されません。「復習データの保存・移行(JSON)」から
書き出し/読み込みができます。読み込み時は問題IDでマージし、同じ回答は重複しません。

## 何切る問題の学習レベル(V1.4)

| レベル | テーマ | 学ぶこと |
|---|---|---|
| LEVEL 1 | 孤立牌・字牌 | まず不要な牌を見つける |
| LEVEL 2 | 両面・嵌張・辺張 | 強い形を残す |
| LEVEL 3 | シャンテン数 | 手を後戻りさせない |
| LEVEL 4 | 受け入れ枚数 | 同じシャンテンなら広い方を選ぶ |
| LEVEL 5 | 複合形 | 複数方向に変化できる形を理解する |

レベルを選ぶと、そのテーマの判断が含まれる手牌だけを出題します(ランダム生成＋条件チェック)。
従来の「ランダム」出題も残しています。

## 「牌譜・復習」タブの使い方

対局中に「牌譜を保存する」を押すと、その対局のここまでの記録が保存されます。「牌譜・復習」タブから
開くと、局ごとに1手(ツモ・打牌・鳴き・リーチ)ずつ「前へ/次へ」で再生できます。14枚(ツモ直後)の
場面では「この時点を分析する」で、実際にはどう切ったか・牌効率上は何を切るべきだったかを比較できます。

## 「局面分析」タブでの実戦局面の扱いについて

任意の14枚の入力・役/符/点数判定・待ち牌判定は引き続き利用できます。加えてV1.3では、
現在の局面(手牌+設定)をJSONとして書き出し/読み込みできる「局面の保存・共有」機能を追加しました
(「局面の保存・共有(JSON)」を展開)。

**制限**: 他家3人の河・副露・リーチ状況まで含めた「実戦局面の完全な再現・入力」は、UIの複雑さと
開発期間のバランスを取り、V1.3では見送りました。実戦の特定の局面(自分の手牌+ドラ+場況)を
再現したい場合は、既存の「局面分析」タブ(自分の手牌+ドラ+自風/場風+アガリ条件)で近似的に
再現するか、上記のJSON機能を使って局面データを保存・受け渡ししてください。

## 使用技術

- HTML / CSS / JavaScript(素のブラウザAPIのみ、フレームワーク・ビルドツール不使用)
- 牌の表示は Unicode 麻雀牌記号(U+1F000〜)+漢字ラベル併記(フォント非対応環境でも判別可能)
- シャンテン数・有効牌・役・符・点数・鳴き・フリテン・CPU判断・安全牌判定は、すべて外部ライブラリを
  使わず自前実装しています。正しさを高めるため、独立実装によるクロスチェック、既知の点数表との
  突き合わせ、大規模な自動対局シミュレーションを行っています(詳細は「検証」章)
- 成績・牌譜の保存は `localStorage` のみ(サーバー・DB・ログイン不要)
- テストは Node.js 標準の `assert` のみを使用した自前の簡易テストランナー

### 大量自動対局シミュレーション

```
node tests/simulate.js 200
```

CPU4人(初心者/標準/強めをローテーション)で東風戦・東南戦を繰り返し自動進行させ、以下を確認します。

- 牌の総数が常に136枚であること、同一牌が5枚以上存在しないこと
- 点数がNaNにならないこと、4人の点数(+供託)の合計が常に100000点であること
- 局が無限ループ・進行停止しないこと
- 和了時に必ず役が成立していること(役なしでアガリ扱いにならないこと)
- 半荘が異常な局数にならず終了し、最終順位が正しく算出されること

直近の実行では **500試合・合計4240局を消化し、エラー0件** でした(下記2件の修正後)。

大量シミュレーションは実際に2件の稀な不具合を検出し、V1.3.1で修正しています。

1. **CPUの停止**: すでに4面子ある状態でさらにポン等を提示してしまい、切る牌が無くなって停止した
   (→ 4面子ある場合・リーチ後・手牌が少なすぎる場合は副露を提示しないよう修正)
2. **点数のNaN**: 役満をツモアガリしたときだけ支払い額のフィールドが未設定で、
   点棒移動がNaNになっていた(約3357局に1回発生。→ 通常役と同じく支払い額を必ず設定するよう修正。
   あわせて点棒移動側にもNaNを持ち込まない保険を追加)

いずれも回帰テストを追加済みで、意図的にバグを戻すとテストが落ちることを確認しています。
点数のNaNは3357局目で初めて現れたため、修正後は4240局(500試合)を通しで消化して
再発しないことを確認しました。

### 計算ロジックの検証

自前実装の正しさを高めるため、以下を行っています。

1. **既知のテストケースの明示的なテスト**: 完成形・各種テンパイ・七対子/国士無双との競合形・
   多対子形、各役の成立/不成立/複合(特にロン時のシャンポン完成による暗刻→明刻への降格、
   鳴き時の食い下がりなど、判定を誤りやすいケース)を明示的にテストしています。
2. **シャンテン計算の独立実装クロスチェック**: `tests/shanten-crosscheck.js` に、本番とは構造の
   異なるアルゴリズムを実装し、800件以上のランダム手牌で計算結果が一致することを確認しています。
3. **点数計算の既知の点数表とのクロスチェック**: 子・親のロン/ツモについて、1〜4翻×30/40/50符、
   および満貫〜役満の点数を、一般的なリーチ麻雀の点数表と突き合わせてテストしています。
4. **牌譜再生の一致性検証**: シミュレーションで進行させた対局のイベントログを再生し、
   最終盤面(各プレイヤーの手牌・副露)が実際の対局結果と完全に一致することをテストしています。

(外部のOSS麻雀ライブラリはネットワーク制約により導入していませんが、本番コードを外部
ライブラリに依存させる変更は行わず、検証用途のみで独立実装・既知の点数表・大量シミュレーションを
用いています)

## 実装している役

| 分類 | 役 |
|---|---|
| 1翻 | リーチ・一発・門前清自摸和・役牌(白/發/中/自風/場風)・タンヤオ・平和・一盃口・海底摸月・河底撈魚・嶺上開花・槍槓 |
| 2翻 | ダブルリーチ・七対子・対々和・三暗刻・三色同順・一気通貫・混全帯幺九・混老頭・三色同刻・小三元 |
| 3翻以上 | 混一色(3)・純全帯幺九(3)・二盃口(3)・清一色(6) |
| 役満 | 国士無双・四暗刻・大三元・小四喜・大四喜・字一色・清老頭・緑一色・九蓮宝燈 |
| ダブル役満(設定可) | 国士無双十三面待ち・四暗刻単騎・純正九蓮宝燈 |

鳴きがある場合、三色同順・一気通貫・混全帯幺九・純全帯幺九・混一色・清一色は食い下がり(翻数-1)が
正しく適用されます。四槓子は役の定義としては用意していますが、カン4回という状況が発生した際の
判定として実装しており、シミュレーションでは未確認の稀なケースです。

## 現在実装済みの機能(V1.3時点)

### 対局・鳴き・安全度(V1.3)
- CPU3人との対局(東風戦・東南戦)、配牌〜終局までの自動進行
- チー・ポン・明槓・暗槓・加槓(槍槓ロン込み)、喰い下がり・門前限定役の正しい判定
- リーチ(門前・テンパイ・1000点以上・山残り確認)、一発・ダブルリーチ・裏ドラ・供託の点棒
- フリテン(捨て牌/一時的/リーチ後)の判定と初心者向け説明
- 4人分の河(捨て牌順・ツモ切り/手出し・鳴かれた牌の区別)
- CPU3段階の強さ(初心者/標準/強め)。シャンテン・受け入れ・役・ドラ・安全度をある程度考慮(ランダム打牌なし)
- 半荘進行(東1〜南4、親移動・連荘・本場・供託・トビ・最終順位)
- 現物・場に4枚見え(絶対安全)、スジ・ワンチャン/ノーチャン(比較的安全)の判定
- 押し引きの参考表示(押し寄り/判断が難しい/オリ寄り、断定はしない)
- 対局中コーチ(OFF/ヒント/フルコーチ)、牌効率・打点・役・安全度の多面的評価、「なぜ?」ボタン
- 牌譜の保存(localStorage)・1手ずつの再生・その時点での打牌分析
- 局面のJSON書き出し・読み込み
- 学習メニュー(初心者向けステップと関連タブへの導線)

### 牌効率・役・点数(V1〜V1.2、維持)
- トレーニング/何切る問題/局面分析、牌効率上のおすすめ・比較表・有効牌の可視化
- 役・翻・符・点数の判定と根拠の解説、ドラ・赤ドラ・裏ドラ、待ち牌判定、アガリ形分解
- 通常手・七対子・国士無双のシャンテン数計算(独立実装によるクロスチェック済み)
- 「現在狙えそうな役」、役が無い場合の説明、成績記録、難易度設定、用語辞典

## 現在の制限

- 他家3人の河・副露・リーチ状況まで含めた実戦局面の完全な手動入力(局面分析タブの拡張)は
  見送りました。局面のJSON書き出し/読み込みで代替できます
- 外部牌譜(雀魂等)の直接インポートは未実装です。内部牌譜はJSON(localStorage)形式で、
  将来的に「外部牌譜→内部標準JSON→本アプリ」のAdapterを追加しやすい構造にはなっています
- CPUは牌効率・役・ドラ・安全度をある程度考慮しますが、深い読み合いをする本格AIではありません
  (優先順位: 一通り遊べる > 主要ルールが正しい > 高度なAI精度、という方針のため)
- 途中流局(四風子連打・九種九牌倒牌など)、喰い替え禁止、複雑な特殊ルール(赤縛り等)は未対応
- 安全牌判定はスジ・ワンチャン/ノーチャン・現物・壁のみで、正確な放銃率計算ではありません
  (根拠のない乱数は使用していません)
- 有効牌の残り枚数は「見えている牌(自分の手牌・全員の捨て牌・副露・ドラ表示牌)」を差し引いた
  理論値です
- 打牌の理由説明・役の説明・コーチのコメントはテンプレートベースの生成であり、AIによる自然言語
  生成は使用していません
- 手牌の形のハイライトや待ちの形の分類は、複合形の場合ひとつの解釈例です。有効牌・受け入れ枚数・
  役・点数そのものの計算は分解の仕方に依存せず常に正確です
- Unicode麻雀牌のグリフは環境によっては簡易的な表示になりますが、漢字ラベルは常に表示されるため
  判別に支障はありません
